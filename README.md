# Pirate Treasure Hunt

An interactive web-based treasure hunt game inspired by Pirates of the Caribbean. Navigate through clues, solve riddles, and compete for the highest score.

## About

This is a browser-based adventure game where players take on the role of a pirate captain searching for legendary treasure. Each clue presents unique challenges inspired by iconic moments from the Pirates of the Caribbean films.

**Game Features:**
- 5 progressive difficulty clues (Easy  Hard)
- Hint system with point deductions
- Combo bonuses for perfect answers
- Score-based treasure tiers (Legendary, Epic, Rare, Common)
- Real-time leaderboard
- Persistent game progress

**Built With:**
- HTML/CSS/JavaScript
- Firebase (Authentication, Firestore, Hosting)
- Vite (Build tool)

## Live Demo

Play now: [https://treasure-hunt0504.web.app](https://treasure-hunt0504.web.app)

## Game Mechanics

Start with 1000 points and navigate through 5 clues. Use hints wisely - they cost points but can help when stuck. Answer incorrectly and lose points. Perfect answers (no hints used) earn combo bonuses.

Your final score determines which treasure you unlock - aim for the Legendary tier!
